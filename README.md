## Завдання

### 1. Обробка одновимірних векторів та сортування

Розробити модуль `vector_algorithms.py`, що генерує випадковий вектор `V` довжиною `N = 21` у діапазоні `[1, 99]`, знаходить його екстремуми, виконує стиснення вилученням нулів через `List Comprehension` та реалізує алгоритм сортування вибором (`Selection Sort`) без використання `.sort()`.

### 2. Матрична алгебра та пошук сідлових точок

Розробити модуль `matrix_operations.py`, що генерує матрицю `A` розмірності `5x3`, виконує перестановку рядків за зростанням їхніх сум, обчислює добуток `A × B` для сумісної матриці `B (3x3)` та реалізує алгоритмічний пошук усіх сідлових точок матриці.

### 3. Конфігураційні кортежі

Забезпечити передачу меж генерації та розмірностей через незмінний конфігураційний кортеж `CONFIG = (N, M, K, X_MIN, X_MAX)` з паралельним розпакуванням.
